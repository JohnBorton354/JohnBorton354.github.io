# My Personal Website

My personal portfolio site, hosted with GitHub Pages.

**Live at:** https://JohnBorton354.github.io

## Structure

- `index.html` — the site itself (all content and styling live here)
- `resume.pdf` — my resume (linked and downloadable from the site)
- `images/` — project screenshots and photos

## Editing

Everything is in `index.html`. To make changes, edit that file, commit, and
push — GitHub Pages redeploys automatically, usually within a minute.

## Setup notes

- Repo must be named `JohnBorton354.github.io` (matching my GitHub username) to serve
  at the root URL.
- Repo must be Public.
- Pages is enabled under Settings → Pages (Source: `main` branch, `/root`).
